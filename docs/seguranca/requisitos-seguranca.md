# Requisitos de segurança testáveis — Webag 1.0 (auth, sessão, pagamentos, upload, LGPD)

- **Dono:** security-engineer | **Data:** 2026-11-18 | **Origem:** `threat-model-auth-pagamento.md` (ameaças T-xx). Achados em ADR/PRD: `revisao-adrs.md`.
- **Faixa de IDs:** SEC-001..099 = requisitos; SEC-101+ = achados.
- **Uso:** os devs implementam; o QA transforma "Como verificar" em teste automatizado (Vitest/Supertest na API, Playwright no web, Maestro no app) ou em roteiro manual. **G4 = Sim** bloqueia o release candidate se falhar. Valores marcados [HIPÓTESE] são configuráveis e o PO pode ajustar sem novo parecer, desde que dentro de ±50%.
- Referências: ASVS 5.0 (V2..V16), API Top 10 2023 (API1..API10), MASVS v2.1. Links no threat model §10.
