## 3. Por que a abertura a frio ainda não bate 2,5 s em 4G lento
O que resta é peso de JS no **web**: 682 KB de JS comprimido (brotli) + 226 KB de fontes + HTML = 909 KB; a 1,6 Mbps isso são ≈ 4,5 s só de transferência. Maiores itens do bundle (bruto, sourcemap): `react-native-reanimated` 643 KB (só no web; no nativo é código nativo), `zod` 235 KB, ícones Solar 160 KB, cliente gerado da API 152 KB, `expo-router` 437 KB e `react-native-web`/`react-dom` 490 KB (plataforma). O **app nativo não baixa JS** (o bytecode Hermes vem no APK): Hermes bytecode Android 7,04 MB (build de 2026-11-19) -> **6,39 MB** (-9%, indicativo: o código-base mudou pouco entre as duas datas). Para o nativo o que conta é carregar/avaliar esse bytecode, o que o item 1 reduz; **não foi medido em aparelho**.
