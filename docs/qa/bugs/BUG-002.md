# BUG-002 | Severidade: Média | Prioridade: P2 | Status: CORRIGIDO e verificado em 2026-11-18

**"Quem fez o quê" devolve os 50 eventos mais antigos (I2)**

Ambiente: API (main, commit ef39555 e posteriores), Node 22, Postgres 16 + Redis reais (banco e Redis próprios do QA).
Descrição: activity ordenava por created_at ascendente com LIMIT 50: a tela congela depois de 50 ações.
Passos: 1. Gerar 60 eventos na loja. 2. GET /v1/stores/{id}/activity.
Esperado: O evento mais recente aparece.   Obtido: (antes) só os 50 mais antigos.
Evidência da regressão: test/qa-regressao-onda2.e2e-spec.ts > I2 passa na execução de 2026-11-18 (ver `docs/qa/relatorios/onda-2.md` §3).
