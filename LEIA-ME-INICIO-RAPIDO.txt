WEBAG - INICIO RAPIDO (abrir o app no seu iPhone, de graca, sem criar conta)
================================================================================

O QUE VOCE VAI TER: o Webag inteiro (API, banco, site, paineis e app) rodando no
seu computador, e o app aberto no SAFARI do iPhone pelo Wi-Fi. Dados e pagamentos
sao de demonstracao: nada e cobrado.

1) INSTALE (uma vez so)             Guia completo: docs/guias/rodar-no-meu-computador.md
   - Git        git-scm.com                       (Mac: vem com as "ferramentas de linha de comando")
   - Node 24    nodejs.org  (escolha a versao 24 de forma explicita; minimo 22.12; nao use a "Current")
   - pnpm       Windows: no Prompt de Comando (cmd, nao PowerShell):  npm install -g pnpm@10.28.0
                Mac: no Terminal:  corepack enable   (se pedir, sudo corepack enable)
   - Docker Desktop  docker.com/products/docker-desktop  (abra e deixe ABERTO)

2) BAIXE E ABRA O TERMINAL NA PASTA
   https://github.com/yagogavilan/webag/archive/refs/heads/main.zip
   Extraia numa pasta curta, sem espacos nem acentos (ex.: C:\webag ou ~/webag). O zip cria a pasta "webag-main":
   a pasta certa e a que tem o arquivo package.json. Windows: botao direito no .zip > Propriedades > Desbloquear,
   antes de extrair (senao o duplo clique no .bat mostra "O Windows protegeu o computador": Mais informacoes > Executar).
   Terminal na pasta (Windows): na barra de endereco do Explorador digite  cmd  e Enter.

3) RODE
   Opcao A, duplo clique:  Mac: iniciar-webag.command    Windows: iniciar-webag.bat
   Opcao B, comandos no terminal (dentro da pasta):
        pnpm install
        pnpm run setup          (com "run"; uma vez so; cria o banco e os dados de demonstracao)
        pnpm iphone             (sobe tudo e mostra o endereco para o iPhone)

4) NO IPHONE (no MESMO Wi-Fi do computador)
   - Safari > digite o endereco que o terminal mostrou (ex.: http://192.168.0.10:8081)
     ou aponte a camera para o QR code do terminal.
   - Opcional: Compartilhar > Adicionar a Tela de Inicio (fica o icone do Webag).
   - Permita "Rede Local" se o iPhone perguntar. A 1a abertura demora.

5) COMPRA DE MENTIRA
   Login: cliente.ana@seed.webag.local   senha: webag-seed-lojista-2026
   Escolha a cidade > loja > produto > sacola > Finalizar com PIX >
   toque em "Simular pagamento". Pronto: pedido recebido.
   (Lojista: lojista.mercadinho-boa-compra@seed.webag.local, mesma senha,
    em http://SEU-IP:3001/lojista/entrar)
   Essas senhas de cliente e lojista sao publicas, so de demonstracao.
   ADMIN (http://SEU-IP:3001/admin/entrar, admin@webag.local): a senha e ALEATORIA,
   fica no arquivo .env como SEED_ADMIN_PASSWORD e o terminal tambem a mostra.
   Cadastre o 2o fator (autenticador) JA NO PRIMEIRO login: veja o README, "Segundo fator do admin".

PARAR: Ctrl+C na janela.   VOLTAR OUTRO DIA: abra o Docker Desktop e rode "pnpm iphone".

SE O IPHONE NAO ABRE: confira o mesmo Wi-Fi (nada de "convidados" ou dados moveis) e
no aviso do firewall marque so "Redes privadas" (guia, secao 6, tem a regra restrita; nao desligue o firewall).
USE SO NO WI-FI DA SUA CASA: enquanto roda, qualquer aparelho do mesmo Wi-Fi acessa o Webag
de teste (so as portas 3000, 3001, 8081 e 9000; banco e Redis ficam so no computador). Nao use em Wi-Fi publico, de cafe, faculdade ou trabalho.
Se o computador tiver mais de uma rede:  pnpm iphone --ip <IP do seu Wi-Fi>
Mais problemas e solucoes: docs/guias/rodar-no-meu-computador.md (secao 6).
